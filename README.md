# CIDS325 — Web Development, Fall 2026

This repository contains course examples and materials for CIDS325 at the University of Wisconsin–River Falls. It will grow throughout the semester as we explore web development. Use it to follow along in class, review what we covered, and experiment with your own changes.

## Get started

Start with a web browser and a code editor. Any additional tools or setup needed for later examples will be introduced in class or explained alongside those materials.

1. Download this repository using **Code → Download ZIP** on GitHub, then extract the ZIP file.
2. Open the extracted folder in your editor.
3. Find the example we are working on in class and follow any setup instructions provided with it. For a basic HTML example, open its HTML file directly in your browser.
4. Keep the editor and browser open side by side so you can compare the source with the rendered page.

If you already use Git, you can clone the repository instead:

```sh
git clone https://github.com/trevortomesh/CIDS325-F26.git
cd CIDS325-F26
```

## Follow along throughout the semester

1. Get the latest materials before class using the update instructions below.
2. Open the example being discussed and follow along with the code and demonstration.
3. Try your own changes, save your work, and refresh the browser or rerun the example as appropriate.
4. Revisit examples after class to practice and explore how they work.

Make one change at a time so you can see what each edit does. Preserve the folder structure when copying examples so that relative links and file references continue to work.

## Troubleshooting

- If your edits do not appear, check that you saved the file, refresh the page, and make sure the browser is showing the same copy you edited.
- If the browser displays source code instead of a page, check that the filename ends in `.html`, not `.html.txt`.
- If a link or resource does not load, check its path and whether it requires an internet connection or additional setup.

## Get updated examples

If you downloaded a ZIP, download a fresh copy when you need updated examples. Keep your practice files in a separate folder so you can preserve your changes.

If you cloned with Git and have no local changes to preserve, run this from the repository folder:

```sh
git pull
```

If Git reports that local changes would be overwritten, preserve your work before updating. Ask for help if you are unsure how to proceed.

Follow the instructions for each course assignment for what to complete and how to submit it; editing your local copy does not submit your work.
